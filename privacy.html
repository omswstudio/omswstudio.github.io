Privacy policy

Hopnib Code is published by OMSW Studio (an individual developer). Contact: omswlab.support@gmail.com. Version 1.0.8 is an offline, free educational game. No registration, login, cloud sync, ads, analytics or purchases are offered in this version. The app stores completed levels, missions, stars and language/sound preferences on the device to support continued play. No name, age or email input is offered. The certificate uses a generic title, not a child’s name. Reports and certificates can be saved locally as PNG/PDF; no in-app sharing is offered.

Parents should supervise use. The parent menu question discourages accidental access and is not verifiable parental consent. This version is designed not to transmit learning data or device identifiers to our servers. Parents may choose to open our website or email application separately; GitHub Pages and email providers may process IP addresses and sender information. Do not send children’s identifying information.

Earlier internal-test releases used Supabase for parent authentication and learning records, and RevenueCat/Google Play for test purchases. Existing account and test records are retained separately; the offline release does not access or erase them. Contact us to request access, correction, deletion, or other applicable rights. We verify authority and explain any necessary limited retention, purpose and period.

To erase local game data, use Android Settings → Apps → Hopnib Code → Storage → Clear data. This permanently removes local progress, settings and archived account snapshots on that device; exported files must be removed separately. For earlier online accounts, email omswlab.support@gmail.com from the registered address if possible. Identify Hopnib Code and the request; do not send passwords, OTPs or children’s personal details. If you cannot access that address, ask for alternative verification. A request is not proof of deletion; the developer will confirm the outcome.
