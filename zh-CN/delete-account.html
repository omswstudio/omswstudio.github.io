删除账户与数据

符合条件的免费账户：打开家长账户 → 隐私与账户 → 永久删除账户。阅读警告，输入 DELETE 并确认当前密码。应用应在确认删除成功后退出登录。

有购买或会员记录的账户可能需要开发者审核后才能删除。所有家长均可通过邮件申请删除账户及关联数据，无需重新安装应用。我们将核实权限，处理适用的支付义务，并实际删除关联数据，而非仅停用账户。若因合法必要原因保留部分记录，将说明类别、目的和保存期限。

已导出或分享的 PNG/PDF 文件、其他设备上的副本及独立游客数据不会自动删除，请分别管理。发送请求不代表删除完成，开发者须在处理后通知结果。

联系开发者

如可行，请使用注册家长账户的邮箱向 omswlab.support@gmail.com 发送邮件。无法访问该邮箱时，可申请其他核实方式。请注明 Hopnib Code 和请求内容。请勿发送密码、验证码、证件号码、银行卡资料或儿童个人信息。我们将核实权限并告知步骤及处理结果。
