家长信息与隐私

Hopnib Code 由个人开发者 OMSW Studio 发布。联系方式：omswlab.support@gmail.com。1.0.8 是免费的离线教育游戏。本版本不提供注册、登录、云同步、广告、分析或购买。已完成关卡、任务、星星及语言和音量设置仅保存在设备上，以便继续游玩。不提供姓名、年龄或邮箱输入栏。证书使用通用称呼而非儿童真实姓名。报告与证书可保存为本地 PNG/PDF，不提供应用内分享。

家长应监督使用。家长菜单中的问题用于减少误操作，不构成法律上的可验证家长同意。本版本设计为不向我们的服务器传送学习数据或设备标识符。家长可自行打开网站或邮件应用；GitHub Pages 和邮件服务商可能处理 IP 地址及发件人信息。请勿发送可识别儿童身份的信息。

账户与数据删除

如需删除设备上的游戏数据，请在 Android 设置→应用→Hopnib Code→存储→清除数据中操作。这会永久删除本机进度、设置及旧账户的本地存档。已导出的文件需另行删除。如需删除早期在线账户，请尽可能使用注册邮箱联系 omswlab.support@gmail.com，说明 Hopnib Code 和请求内容。不要发送密码、验证码或儿童个人信息。无法使用注册邮箱时，请申请其他验证方式。提交请求并不代表已经删除，开发者将告知处理结果。
