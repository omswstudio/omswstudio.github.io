隐私政策

Hopnib Code 由以 OMSW Studio 名义运营的个人开发者发布。联系方式：omswlab.support@gmail.com。

Hopnib Code 是面向儿童的学习游戏。World 1 无需创建账户即可游玩。游客进度保存在设备上，经家长确认后可导入家长账户。

Supabase Auth 处理家长邮箱、密码及认证信息，用于账户管理和密码重置。联网同步会保存账户标识、已完成的关卡和任务。 未开放世界的旧版学习同步代码还包含答案、练习、学习报告及同步标识的保存功能。这些世界在本版本中尚未向公众开放。

World 1 的星星、徽章、奖杯和报告根据进度计算。可选昵称和年龄按账户保存在本机。证书姓名用于当次证书生成。声音和语言设置保存在设备上。导出或分享的 PNG/PDF 文件可能留在本机或家长选择的服务中。

Supabase 提供认证和学习数据存储服务，目前项目位于新加坡。可能保留历史测试购买、权益和旧支付记录。内部购买测试使用了 Google Play 和 RevenueCat，但本封闭测试版禁用新购买及 RevenueCat 购买 SDK。账户和进度数据在提供服务所需期间或直至申请删除时保留；为遵守法律、防止欺诈或解决争议，可能保留必要记录。数据可能在您所在国家以外处理。如需了解保存期限或申请删除，请联系我们。退出登录不等于删除账户。

本站没有我们添加的数据输入表单或跟踪脚本。如托管在 GitHub Pages，托管服务商可能出于安全目的记录 IP 地址。发送邮件时，邮件服务商会处理邮件及发件人信息以投递并处理请求。

儿童隐私

账户和邮箱应属于家长或监护人。请勿让儿童填写自己的邮箱、住址、电话号码、学校或其他不必要的个人信息，包括在昵称栏填写真实姓名。

家长可查看进度、清除本机学习者档案及管理账户。家长验证的算术题仅用于防止误入，不等于符合法律要求的可验证家长同意。

家长或监护人可联系 omswlab.support@gmail.com 申请访问、更正、删除、撤回同意、提出异议或行使其他适用法律权利。我们将核实申请权限。请勿提交可识别儿童身份的信息。如法律要求在在线收集儿童个人信息之前直接通知家长并取得可验证同意，必须先满足这些要求。

联系开发者

如可行，请使用注册家长账户的邮箱向 omswlab.support@gmail.com 发送邮件。无法访问该邮箱时，可申请其他核实方式。请注明 Hopnib Code 和请求内容。请勿发送密码、验证码、证件号码、银行卡资料或儿童个人信息。我们将核实权限并告知步骤及处理结果。
