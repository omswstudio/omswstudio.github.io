隐私政策

Coding Adventure Junior 由以 OMSW Studio 名义运营的个人开发者发布。联系方式：omswlab.support@gmail.com。

Coding Adventure Junior 是面向儿童的学习游戏。World 1 无需创建账户即可游玩。游客进度保存在设备上，经家长确认后可导入家长账户。

Supabase Auth 处理家长邮箱、密码及认证信息，用于账户管理和密码重置。联网同步会保存账户标识、已完成的关卡和任务。Jin 的旧版 World 2 代码还支持保存答题、练习、学习报告及同步用设备标识，但本版本尚未向公众开放 Jin 的世界。

World 1 的星星、徽章、奖杯和报告根据进度计算。可选昵称和年龄按账户保存在本机。证书姓名用于当次证书生成。声音和语言设置保存在设备上。导出或分享的 PNG/PDF 文件可能留在本机或家长选择的服务中。

Supabase 提供认证和学习同步所需的账户及数据库服务。可能仍保留历史订单、会员及原支付服务商记录。账户和进度数据用于提供服务，直至申请删除或不再需要。为遵守法律、防止欺诈或解决争议，可能需要保留少量记录。正式发布前须确认并披露各类数据的实际保存期限、备份、存储地区、跨境传输及全部服务商。退出登录不等于删除账户。

本站没有我们添加的数据输入表单或跟踪脚本。如托管在 GitHub Pages，托管服务商可能出于安全目的记录 IP 地址。发送邮件时，邮件服务商会处理邮件及发件人信息以投递并处理请求。

儿童隐私

账户和邮箱应属于家长或监护人。请勿让儿童填写自己的邮箱、住址、电话号码、学校或其他不必要的个人信息，包括在昵称栏填写真实姓名。

家长可查看进度、清除本机学习者档案及管理账户。家长验证的算术题仅用于防止误入，不等于符合法律要求的可验证家长同意。

家长或监护人可联系 omswlab.support@gmail.com 申请访问、更正、删除、撤回同意、提出异议或行使适用法律规定的其他权利。开发者须先核实申请人的权限。公开版本在线收集儿童个人信息前，须落实并核实直接通知家长及依法获取可验证家长同意的机制。

联系开发者

如可行，请使用注册家长账户的邮箱向 omswlab.support@gmail.com 发送邮件。无法访问该邮箱时，请申请其他身份核实方式。注明 Coding Adventure Junior 及删除账户与关联数据的要求，或所需行使的隐私权利。请勿发送密码、验证码、证件号码、银行卡资料或儿童个人信息。开发者须查看邮件、核实权限并告知步骤及处理结果。
