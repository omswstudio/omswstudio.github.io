プライバシーポリシー

Hopnib Code は個人開発者が OMSW Studio の名称で提供します。連絡先：omswlab.support@gmail.com。

Hopnib Code は子ども向けの学習ゲームです。World 1 はアカウントなしで遊べます。ゲストの進捗は端末に保存され、保護者の確認後に保護者アカウントに取り込めます。

アカウント管理とパスワード再設定には Supabase Auth が保護者のメールアドレス、パスワード、認証情報を処理します。オンライン同期ではアカウント識別子、クリアしたステージとミッションを保存します。 未公開ワールド向けの旧学習同期コードには、回答、練習、学習レポート、同期用識別子の保存機能もあります。これらのワールドは本版では一般利用できません。

World 1 のスター、メダル、トロフィー、レポートは進捗から算出します。任意のニックネームと年齢はアカウントごとに端末に保存し、修了証の名前は入力時の修了証作成に使用します。音量と言語設定は端末に保存します。出力・共有した PNG/PDF は端末や保護者が選んだサービスに残る場合があります。

認証と学習記録の保存には Supabase を利用し、現在のプロジェクトはシンガポールにあります。過去のテスト購入、利用権、決済記録が残る場合があります。内部購入テストでは Google Play と RevenueCat を利用しましたが、本クローズドテスト版では新規購入と RevenueCat 購入 SDK を無効にしています。アカウントと進捗はサービス提供に必要な期間、または削除申請まで保存し、法令遵守、不正防止、紛争解決に必要な記録は例外として保存する場合があります。国外で処理される場合があります。保存期間や削除についてはお問い合わせください。ログアウトは削除ではありません。

このサイトには当方が追加した入力フォームや追跡スクリプトはありません。GitHub Pages に公開する場合、ホスティング事業者はセキュリティ目的で IP アドレスを記録することがあります。メール送信時にはメール事業者が配信と申請対応のために本文や送信者情報を処理します。

子どものプライバシー

アカウントとメールアドレスには保護者のものを使用してください。子ども自身のメールアドレス、住所、電話番号、学校、ニックネーム欄への本名など、不要な個人情報を入力しないでください。

保護者は進捗の確認、端末のプロフィールの消去、アカウント管理ができます。計算問題の保護者ゲートは誤操作防止であり、法的に有効な保護者の同意を確認する仕組みではありません。

保護者は omswlab.support@gmail.com に連絡し、適用法に基づく閲覧、訂正、削除、同意の撤回、異議申立て等を請求できます。申請者の権限を確認して対応します。子どもを特定する情報は送信しないでください。法令が子どもの個人情報のオンライン収集前に保護者への直接通知と確認可能な同意を求める場合、その要件を満たす必要があります。

開発者への連絡

可能であれば登録済みの保護者メールアドレスから omswlab.support@gmail.com にご連絡ください。利用できない場合は別の確認方法をご相談ください。Hopnib Code と申請内容を明記し、パスワード、認証コード、身分証番号、カード情報、子どもの個人情報は送信しないでください。権限を確認し、手順と結果をご案内します。
