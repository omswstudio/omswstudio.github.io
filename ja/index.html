保護者向け情報とプライバシー

Hopnib Code は個人開発者 OMSW Studio が提供します。連絡先：omswlab.support@gmail.com。バージョン1.0.8は無料のオフライン学習ゲームです。登録、ログイン、クラウド同期、広告、分析、購入機能はありません。クリアしたステージ、ミッション、星、言語・音量設定は端末内に保存します。氏名、年齢、メールアドレスの入力欄はありません。修了証は一般的な呼称を使用し、実名は使用しません。レポートと修了証はPNG/PDFとして端末に保存できます。アプリ内共有機能はありません。

保護者の方は利用を見守ってください。保護者メニューの問題は誤操作防止用であり、法的な保護者同意の確認ではありません。本版は学習データや端末識別子を当社サーバーに送信しない設計です。保護者が別途ウェブサイトやメールアプリを利用すると、GitHub Pagesやメール提供者がIPアドレスや送信者情報を処理する場合があります。お子さまを特定できる情報は送らないでください。

アカウントとデータの削除

端末内データを削除するにはAndroidの設定→アプリ→Hopnib Code→ストレージ→データを消去を選択します。端末内の進捗、設定、旧アカウントの保存記録が永久に消去されます。出力したファイルは別途削除してください。以前のオンラインアカウントの削除は、可能なら登録済みメールアドレスからomswlab.support@gmail.comへHopnib Codeと依頼内容をお知らせください。パスワード、OTP、お子さまの個人情報は送らないでください。登録メールが使えない場合は別の確認方法をご相談ください。依頼だけで削除が完了するわけではなく、結果をご案内します。
