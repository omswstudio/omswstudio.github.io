การลบบัญชีและข้อมูล

หากต้องการลบข้อมูลเกมในเครื่อง ให้ไปที่การตั้งค่า Android → แอป → Hopnib Code → ที่เก็บข้อมูล → ล้างข้อมูล การดำเนินการนี้ลบความคืบหน้า การตั้งค่า และสำเนาบัญชีเดิมบนเครื่องอย่างถาวร ต้องลบไฟล์ที่ส่งออกแยกต่างหาก สำหรับบัญชีออนไลน์เดิม ส่งอีเมลถึง omswlab.support@gmail.com จากอีเมลที่สมัครหากทำได้ ระบุ Hopnib Code และคำขอ ไม่ต้องส่งรหัสผ่าน OTP หรือข้อมูลเด็ก หากเข้าอีเมลเดิมไม่ได้ ให้ขอวิธียืนยันอื่น การส่งคำขอไม่ใช่การยืนยันว่าลบแล้ว ผู้พัฒนาจะแจ้งผล

รุ่นทดสอบภายในก่อนหน้านี้ใช้ Supabase จัดการบัญชีผู้ปกครองและข้อมูลการเรียน และใช้ RevenueCat/Google Play สำหรับรายการซื้อทดสอบ ข้อมูลบัญชีและรายการทดสอบเดิมเก็บแยกไว้ รุ่นเล่นบนเครื่องไม่เข้าถึงหรือทำลายข้อมูลดังกล่าว ติดต่อเราเพื่อขอเข้าถึง แก้ไข ลบ หรือใช้สิทธิตามกฎหมาย เราจะตรวจสอบสิทธิของผู้ร้องขอและแจ้งข้อมูลที่จำเป็นต้องเก็บต่อ วัตถุประสงค์ และระยะเวลา
