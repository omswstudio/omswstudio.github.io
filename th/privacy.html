นโยบายความเป็นส่วนตัว

Coding Adventure Junior เผยแพร่โดยผู้พัฒนาบุคคลธรรมดาภายใต้ชื่อ OMSW Studio ติดต่อ omswlab.support@gmail.com.

Coding Adventure Junior เป็นเกมฝึกคิดและเขียนโปรแกรมสำหรับเด็ก ผู้ปกครองสามารถให้เด็กเล่น World 1 โดยไม่ต้องสมัครบัญชีได้ ความคืบหน้าแบบ Guest จะเก็บในเครื่อง และสามารถเลือกนำเข้าไปยังบัญชีผู้ปกครองได้เมื่อยืนยันด้วยตนเอง

เมื่อสมัครหรือเข้าสู่ระบบ ระบบ Supabase Auth ใช้อีเมล รหัสผ่าน และข้อมูลยืนยันตัวตนของผู้ปกครองเพื่อจัดการบัญชีและรีเซ็ตรหัสผ่าน เมื่อออนไลน์ ระบบบันทึกหมายเลขบัญชี ด่าน และภารกิจที่ผ่านเพื่อให้เล่นต่อได้ ในโค้ดเดิมสำหรับ Jin (World 2 เดิม) ยังมีระบบบันทึกคำตอบ แบบฝึกหัด รายงานการเรียนรู้ และรหัสอุปกรณ์สำหรับการซิงค์ แม้โลกของ Jin ยังไม่เปิดให้เล่นทั่วไปในรุ่นนี้

ดาว เหรียญ ถ้วยรางวัล และรายงาน World 1 คำนวณจากความคืบหน้า ชื่อเล่นและอายุเด็กเป็นข้อมูลไม่บังคับ จัดเก็บในเครื่องแยกตามบัญชี ชื่อบนใบประกาศจะใช้สร้างใบประกาศที่กรอกในขณะนั้น การตั้งค่าเสียงและภาษาเก็บในเครื่อง หากบันทึกหรือแชร์ PNG/PDF ไฟล์อาจอยู่ในเครื่องหรือบริการที่ผู้ปกครองเลือกแชร์

Supabase ให้บริการบัญชีและฐานข้อมูลเพื่อยืนยันตัวตนและซิงค์การเรียนรู้ ระบบเดิมอาจมีข้อมูลคำสั่งซื้อและสิทธิ์สมาชิก รวมถึงข้อมูลผู้ให้บริการชำระเงินเดิม ข้อมูลบัญชีและความคืบหน้าจำเป็นต่อการให้บริการจนกว่าจะขอลบหรือหมดความจำเป็น อาจต้องเก็บข้อมูลเฉพาะส่วนเพื่อปฏิบัติตามกฎหมาย ป้องกันทุจริต หรือระงับข้อพิพาท ระยะเวลาเก็บจริงของข้อมูลแต่ละประเภท สำเนาสำรอง ภูมิภาคที่จัดเก็บ และผู้ให้บริการทั้งหมดต้องตรวจสอบและระบุให้ครบก่อนเผยแพร่จริง การออกจากระบบไม่ใช่การลบบัญชี

เว็บไซต์นโยบายนี้ไม่มีแบบฟอร์มเก็บข้อมูลและไม่มีสคริปต์ติดตามที่เราเพิ่มไว้ หากเผยแพร่ผ่าน GitHub Pages ผู้ให้บริการอาจบันทึก IP เพื่อความปลอดภัย เมื่อส่งอีเมล ผู้ให้บริการอีเมลจะประมวลผลข้อความและข้อมูลผู้ส่งเพื่อรับและจัดการคำขอ

ความเป็นส่วนตัวของเด็ก

บัญชีและอีเมลควรเป็นของผู้ปกครอง ไม่ควรให้เด็กกรอกอีเมลของตนเองหรือข้อมูลที่ไม่จำเป็น เช่น ที่อยู่ เบอร์โทรศัพท์ โรงเรียน หรือชื่อจริงในช่องชื่อเล่น

ผู้ปกครองสามารถตรวจความคืบหน้า ล้างโปรไฟล์ในเครื่อง และจัดการข้อมูลผ่านเมนูบัญชีผู้ปกครอง คำถามคณิตศาสตร์ก่อนเข้าบัญชีช่วยป้องกันการกดเข้ามาโดยไม่ตั้งใจ ไม่ใช่การยืนยันความยินยอมของผู้ปกครองตามกฎหมาย

ผู้ปกครองสามารถติดต่อ omswlab.support@gmail.com เพื่อขอเข้าถึง แก้ไข ลบข้อมูล ถอนความยินยอม หรือคัดค้านและใช้สิทธิอื่นตามกฎหมายที่เกี่ยวข้อง ผู้พัฒนาต้องตรวจสอบสิทธิของผู้ร้องขออย่างเหมาะสมก่อนดำเนินการ การเปิดรับข้อมูลเด็กออนไลน์ต้องผ่านการตรวจสอบการแจ้งผู้ปกครองและความยินยอมที่ตรวจสอบได้เมื่อกฎหมายกำหนดก่อนเผยแพร่

ติดต่อผู้พัฒนา

ส่งอีเมลถึง omswlab.support@gmail.com จากอีเมลที่ใช้สมัครบัญชี (หากเข้าถึงไม่ได้ ให้แจ้งเพื่อขอวิธียืนยันตัวตนอื่น) ระบุว่าเป็น Coding Adventure Junior และต้องการลบบัญชีพร้อมข้อมูล หรือระบุสิทธิที่ต้องการใช้ ไม่ต้องส่งรหัสผ่าน OTP เลขบัตร ข้อมูลบัตรชำระเงิน หรือข้อมูลส่วนบุคคลของเด็ก ผู้ดูแลจะต้องตรวจกล่องอีเมล ยืนยันสิทธิ แจ้งขั้นตอนและผลการจัดการคำขอ
