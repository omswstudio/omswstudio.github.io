Hopnib Code เป็นเกมฝึกคิดและเขียนโปรแกรมสำหรับเด็ก ผู้ปกครองสามารถให้เด็กเล่น World 1 โดยไม่ต้องสมัครบัญชีได้ ความคืบหน้าแบบ Guest จะเก็บในเครื่อง และสามารถเลือกนำเข้าไปยังบัญชีผู้ปกครองได้เมื่อยืนยันด้วยตนเอง

เมื่อสมัครหรือเข้าสู่ระบบ ระบบ Supabase Auth ใช้อีเมล รหัสผ่าน และข้อมูลยืนยันตัวตนของผู้ปกครองเพื่อจัดการบัญชีและรีเซ็ตรหัสผ่าน เมื่อออนไลน์ ระบบบันทึกหมายเลขบัญชี ด่าน และภารกิจที่ผ่านเพื่อให้เล่นต่อได้ แอปยังมีโค้ดซิงค์การเรียนรู้เดิมสำหรับโลกที่ยังไม่เปิด เช่น คำตอบ แบบฝึกหัด รายงาน และรหัสสำหรับการซิงค์ โลกเหล่านี้ยังไม่เปิดให้เล่นทั่วไปในรุ่นนี้

ดาว เหรียญ ถ้วยรางวัล และรายงาน World 1 คำนวณจากความคืบหน้า ชื่อเล่นและอายุเด็กเป็นข้อมูลไม่บังคับ จัดเก็บในเครื่องแยกตามบัญชี ชื่อบนใบประกาศจะใช้สร้างใบประกาศที่กรอกในขณะนั้น การตั้งค่าเสียงและภาษาเก็บในเครื่อง หากบันทึกหรือแชร์ PNG/PDF ไฟล์อาจอยู่ในเครื่องหรือบริการที่ผู้ปกครองเลือกแชร์

Supabase ให้บริการยืนยันตัวตนและจัดเก็บข้อมูลการเรียนรู้ โดยโปรเจกต์ปัจจุบันอยู่ในภูมิภาคสิงคโปร์ อาจมีข้อมูลรายการซื้อทดสอบ สิทธิ์ และรายการชำระเงินเดิมคงอยู่ เราใช้ Google Play และ RevenueCat ในการทดสอบการซื้อภายใน แต่รุ่นทดสอบแบบปิดนี้ปิดการซื้อใหม่และ SDK การซื้อของ RevenueCat ข้อมูลบัญชีและความคืบหน้าเก็บเท่าที่จำเป็นต่อการให้บริการหรือจนกว่าจะขอลบ โดยอาจเก็บเฉพาะส่วนที่จำเป็นตามกฎหมาย การป้องกันทุจริต หรือการระงับข้อพิพาท ข้อมูลอาจถูกประมวลผลนอกประเทศของคุณ ติดต่อเราเพื่อสอบถามระยะเวลาเก็บข้อมูลที่เกี่ยวข้องและขอลบข้อมูล การออกจากระบบไม่ใช่การลบบัญชี

เว็บไซต์นโยบายนี้ไม่มีแบบฟอร์มเก็บข้อมูลและไม่มีสคริปต์ติดตามที่เราเพิ่มไว้ หากเผยแพร่ผ่าน GitHub Pages ผู้ให้บริการอาจบันทึก IP เพื่อความปลอดภัย เมื่อส่งอีเมล ผู้ให้บริการอีเมลจะประมวลผลข้อความและข้อมูลผู้ส่งเพื่อรับและจัดการคำขอ
